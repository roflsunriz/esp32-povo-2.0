# povo CYD 常時表示

パッチ版povo 2.0が取得したトッピング終了日時を、PC中継経由で専用のESP32-2432S028R（ILI9341、320×240横画面）に表示します。コード適用と自動更新はAndroidアプリが担当します。

```text
パッチ版povoアプリ → HTTPS PUT → PC中継 ← HTTPS GET ← CYD
```

初回リリースは実機未検証のプレビューです。リリースの `povo-cyd-source.zip` を展開し、[設定・ビルド手順](how-to-update.md)へ進んでください。配布物に個人設定や設定済みファームウェアは含まれません。

## 用意するもの

- この用途専用のESP32-2432S028Rと2.4 GHz Wi-Fi
- CYD表示用APIに対応する[povo-2.0-revanced](https://github.com/roflsunriz/povo-2.0-revanced)
- Python 3.10以降を実行できるPC、およびAndroidが信頼するHTTPS証明書
- ファームウェアを構築するPlatformIO Core

## PCとAndroidを設定する

PC中継は関連プロジェクトの既存実装を利用します。[中継の起動・証明書・トークン設定](https://github.com/roflsunriz/povo-2.0-revanced/blob/main/relay/README.md)に従い、PCで中継を起動してください。ローカルにある場合は、そのリポジトリで `python -m relay.server` を実行します。

1. 異なる書き込み用・読み取り用トークンを設定します。
2. Androidの「CYD表示用API」にHTTPSの `/api/v1/status` URLと書き込み用トークンを設定します。
3. 「保存して送信」の後に「送信結果を確認」で成功を確認します。
4. CYDには同じURL、読み取り用トークン、証明書を検証するルートCAを設定します。

PCは起動・ネットワーク接続を維持してください。スリープ中は中継できません。Androidのバックグラウンド送信は15分以上の間隔となり、省電力管理で遅れる場合があります。

## 表示の意味

- APIを5分ごとに取得し、受信した時刻と端末内の経過時間から残り日数・時間を更新します。
- 主な期限は**現在のトッピング終了日時**です。コードの入力期限とは異なります。
- サーバー確認・手動設定・推定・不明を区別します。推定値や期限経過は更新成功の証拠ではありません。
- 通信に失敗しても起動中に受け取った最後の期限でカウントダウンを続け、通信異常を表示します。古い情報は同期停止として扱います。
- 回数はアプリが記録した成功回数で、povo側の残回数照会結果ではありません。
- 再起動後は再取得するまで未受信になります。CYDからコード適用やpovoへの直接通信は行いません。
