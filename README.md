# povo CYD 常時表示

専用ESP32-2432S028R（ILI9341、320×240）がpovoへ直接ログインし、適用中のデータ使い放題の期限を表示します。パッチ版povoアプリとPC中継の常時稼働は不要です。

```text
初回: スマホのブラウザ → CYDでメール認証
通常: povo公式API ← HTTPS → CYD
```

v0.3.0ではCYDの直接認証・期限表示・再起動保持・Wi-Fi自動復帰を実機確認しました。v0.5.0では専用基板でペン校正と再起動後のタブ操作を確認し、見つかった画面残像はv0.5.1で修正して実機確認しました。残る確認項目は[検証結果](verification.md)を参照してください。

## 使い始める

1. 専用CYDと2.4 GHz Wi-Fiを用意し、[ビルド・設定手順](how-to-update.md)に従ってWi-Fi設定入りのファームウェアを書き込みます。
2. CYDに表示された `povo-setup-…` のWi-Fiへ、表示されたパスワードでスマホを接続します。
3. スマホのブラウザで `http://192.168.4.1` を開き、povo登録メールアドレスを入力して「コードを送る」を押します。
4. **今回届いた6桁のコードを2分以内に**入力します。期限切れは再送してください。再送間隔は30秒以上です。
5. ログイン成功後は設定用Wi-Fiが終了します。スマホを通常のWi-Fiに戻してください。

認証はCYDに保存され、再起動時に読み込みます。期限が近づくと認証を更新します。サーバーに認証を拒否された場合は設定用Wi-Fiが再び開きます。PINなどメールOTP以外の追加認証を要求するアカウントでは、未対応の認証方式と表示します。

## 表示する情報

- povoから通常は設定した間隔（初期値5分、60〜600秒で変更可）ごとに取得し、起動中は毎秒表示を更新します。残り30分以下の期限間近と期限切れ後は、1分ごとに取得します。カバレッジがリニューされて期限が延びると、通常取得に戻ります。状態表示には次の取得までの残り時間（例: 最終同期 3分前 次回あと4分12秒）と取得中の表示も出ます。
- 日本語の「適用中」「使い放題」に該当するトッピングを選び、複数ある場合は最も早い期限を表示します。
- 残り時間は「残り○日○時間」の数値表示に加え、残量に応じて左から縮む減るタイプのプログレスバーでも示します。
- 期限は公式画面データの日本時間・分単位の表記に基づきます。秒単位の厳密な終了時刻ではありません。
- 対象のトッピングがなければ期限は「不明」です。取得失敗時は起動中の最後の正常値を保持し、15分以上更新できなければ同期停止と表示します。期限間近・期限切れ後の取得は128kbps級の低速回線でも成功できるよう通信の制限時間を延ばしています。
- 画面上部のタブで「表示」と「自動消灯」を切り替えます。
- 表示内容が変わった画面領域だけを更新し、同期時の画面のちらつきを抑えます。
- 自動消灯は0〜59分のスライダーと0〜24時間のスライダー、取得間隔は60〜600秒（60秒刻み）のスライダーで調整します。0分0時間は自動消灯オフ（常時点灯）と同じです。タブ内はスクロールバーや内容ドラッグで移動できます。無操作が設定時間続くとバックライトと液晶を休止し、画面タッチで復帰します。消灯中も期限の取得は続けます。
- BOOTボタンを1回押すと画面が上下反転します。消灯設定と画面向きは本体に保存され、再起動後も保持されます。
- タッチ位置がずれる、または軽いペン操作が反応しない場合は、起動後にBOOTボタンを1.5秒以上押して離します。画面の十字を左上、右下の順に普段使うペンで押して離すと、位置と押圧感度を調整して保存します。反応がなければ、抵抗膜を押せるペンか画面の保護シートを確認してください。
- このファームウェアはプロモコード適用・購入・自動再適用を行いません。旧パッチが記録した適用回数や自動更新状態は表示しません。
